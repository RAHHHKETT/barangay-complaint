# KPIs — Barangay Complaint System

## Key Performance Indicators

### KPI 1: Defect Rate
- **Definition:** Number of bugs found vs total features delivered
- **Formula:** (Total Bugs / Total Features) × 100
- **Current:** 1 bug found / 6 features = 16.7%
- **Target:** Below 10%
- **Status:** 🟡 Needs Improvement

### KPI 2: Lead Time
- **Definition:** Time from first commit to successful deployment
- **Formula:** Deployment date - First commit date
- **Current:** 1 day
- **Target:** Under 3 days
- **Status:** 🟢 Met

### KPI 3: Deployment Frequency
- **Definition:** How often we deploy to production
- **Formula:** Number of deployments per week
- **Current:** 3 deployments per week
- **Target:** At least 1 per week
- **Status:** 🟢 Met

### KPI 4: Response Time
- **Definition:** Page load time of the live site
- **Formula:** Measured via browser DevTools Network tab
- **Current:** ~1.4 seconds
- **Target:** Under 3 seconds
- **Status:** 🟢 Met

### KPI 5: Availability
- **Definition:** Percentage of time the system is accessible
- **Formula:** (Uptime / Total Time) × 100
- **Current:** 99.9% (Vercel SLA)
- **Target:** Above 99%
- **Status:** 🟢 Met
